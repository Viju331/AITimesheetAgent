# P0-005 - MVP Scope

## Included

### AI Tool Support

* Claude Code
* Cursor
* Codex

### Activity Sources

* AI Sessions
* Git Activity

### Features

* Project Discovery
* Session Parsing
* Activity Timeline
* Style Learning
* Timesheet Generation
* Export

## Excluded

* Jira
* Planner
* Azure DevOps
* Slack
* Teams
* Automatic Submission
* Analytics Dashboard

## MVP Success Definition

User generates a complete daily update from AI sessions and Git activity without manually writing the report.
