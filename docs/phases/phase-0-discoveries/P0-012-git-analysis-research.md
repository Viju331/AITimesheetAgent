# P0-012 - Git Analysis Research

## Objective

Define how Git activity will be analyzed.

---

# Activity Sources

## Commits

Capture:

* Hash
* Author
* Date
* Message

---

## Modified Files

Capture:

* File Name
* Folder
* Extension

---

## Branches

Capture:

* Current Branch
* Active Feature Branch

---

# Analysis Goals

Detect:

* New Features
* Bug Fixes
* Refactoring
* Unit Testing
* Documentation

---

# Commands To Evaluate

```bash
git log

git diff

git status

git show

git branch
```

---

# Deliverables

Git Analysis Design Document
Git Activity Model
Activity Classification Rules
