# P0-002 - Business Requirements

## Functional Requirements

### FR-001

User can install the desktop application.

### FR-002

User can configure AI tools.

### FR-003

User can configure project root folders.

### FR-004

System can discover projects automatically.

### FR-005

System can read today's AI sessions.

### FR-006

System can analyze Git activity.

### FR-007

System can generate activity summaries.

### FR-008

System can generate timesheet updates.

### FR-009

User can export generated updates.

### FR-010

User can review and edit generated content before export.

## Non Functional Requirements

### NFR-001

Application startup < 5 seconds.

### NFR-002

Project scanning < 30 seconds.

### NFR-003

Summary generation < 15 seconds.

### NFR-004

Support 100+ projects.

### NFR-005

Support Windows 10 and Windows 11.
